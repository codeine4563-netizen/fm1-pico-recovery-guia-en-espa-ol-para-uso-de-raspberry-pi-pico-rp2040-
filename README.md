# Guía: reparar un M-VAVE FM-1 brickeado con una Raspberry Pi Pico

Guía comunitaria no oficial, en español, para Windows y PowerShell. Explica paso a paso cómo recuperar un M-VAVE FM-1 que no enciende (hardbrick) usando una Raspberry Pi Pico.

**[Abrir la guía en PDF](guia-fm1-pico.pdf)**

## Antes de empezar

- Se probó con un solo equipo y funcionó.
- Hay un paso que escribe en la memoria del FM-1. Úsala bajo tu propio riesgo.
- Haz siempre un respaldo de la memoria de TU FM-1 antes de escribir.
- No está afiliada a M-VAVE ni a JieLi.

## Qué NO incluye este repositorio

No incluye ni redistribuye archivos de otros proyectos ni de M-VAVE (el firmware oficial `FM-1.fwsc`, `wl82loader.bin`, etc.). Descárgalos de sus páginas con los enlaces de abajo.
